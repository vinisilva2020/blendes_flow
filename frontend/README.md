# Frontend

Frontend Vue 3 + Vite do BlendES Flow.

```powershell
python scripts/bootstrap_env.py
cd frontend
npm ci
npm run dev
```

Acesse `http://localhost:5173`. A configuração fica exclusivamente no `.env`
da raiz; não crie arquivos de ambiente neste diretório.

Consulte o [guia completo](../docs/frontend/README.md).
